# 视频发布文案固定门店区设计

## 目标

视频发布标题、正文、商品亮点和动态话题由 AI 根据当前视频脚本生成；门店名称、完整地址和营业时间由服务端根据任务 `shop_id` 读取并追加，AI 无权生成或改写。

## 输出结构

1. 动态区：`title`、`body`、`hashtags`、`first_comment`。
2. 固定区：`shop_details.name`、`shop_details.address`、`shop_details.business_hours`、`shop_details.block`、`shop_details.locked=true`。
3. 最终正文：清洗后的动态正文 + 两个换行 + 固定门店块。

固定块格式：

```text
📍 BOOMER OFF vintage 中信泰富店
🏢 上海市静安区南京西路1168号 中信泰富广场 B1层 B16，近泰兴路
🕙 营业时间：每天 10:00–22:00
```

## 规则

- 模型提示词不得要求模型生成地址或营业时间。
- 模型输出中的地址、坐标、营业时间行会在服务端被移除。
- `shop_id` 对应门店是固定信息的唯一来源。
- 固定块可由管理员修改门店资料，但不能在单条视频文案编辑中被 AI 覆盖。
- 没有门店时不编造固定块，并在返回数据中标记 `locked=false`。
- 已缓存的旧文案再次读取时也要补齐固定块，保证发布中心和素材详情一致。

## 验收

- AI 即使返回错误地址和错误营业时间，最终正文也只出现数据库门店资料。
- Director 自动生成和素材详情重新生成都使用同一共享函数。
- 文案复制与一键发布读取到的 `video_copy.body` 已包含固定门店块。
